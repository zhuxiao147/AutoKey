# 自动按键设置工具

这是一个基于Qt和C++开发的自动按键设置工具，用于与HID键盘模拟设备进行交互。

## 功能特性

- **HID设备连接**: 支持连接指定VID和PID的HID设备（0x1234, 0x5678）
- **按键序列设置**: 支持设置复杂的按键序列
- **语法验证**: 提供按键序列语法检查功能
- **数据协议**: 实现完整的数据协议，包含长度、数据和CRC32校验

## 按键序列语法

- `"A;"`：表示按下并松开A键
- `"Ctrl+A;"`：表示按下Ctrl键和A键，松开时先松开A键再松开Ctrl键
- `"A(5);"`：表示按下并松开A键5次
- `"100ms;"`：表示等待100毫秒

### 示例
- `"A;Ctrl+A;A(5);100ms;"`：表示先按下并松开A键，然后按下Ctrl键和A键，松开时先松开A键再松开Ctrl键，接着按下并松开A键5次，最后等待100毫秒

## 支持的按键

- 字母键：A-Z
- 数字键：0-9
- 功能键：F1-F12
- 特殊键：Enter, Esc, Backspace, Tab, Space
- 修饰键：Ctrl, Shift, Alt, Win

## 构建要求

- Qt 5.12 或更高版本
- C++11 编译器
- Windows SDK（用于HID支持）

## 构建步骤

1. 安装Qt开发环境
2. 打开命令行，进入项目目录
3. 运行以下命令：
```bash
qmake AutoKeyTool.pro
make  # 或 nmake（Windows）
```

## 使用方法

1. 运行程序后，点击"连接设备"按钮连接HID设备
2. 在输入框中输入按键序列
3. 点击"检查序列"验证语法是否正确
4. 点击"发送序列"将按键序列发送到HID设备

## 数据协议

发送给HID设备的数据格式：
- **length**: 4字节（data的长度）
- **data**: 按键序列数据
- **crc32**: 4字节（data的crc32校验值）

## 注意事项

- 确保HID设备的VID和PID与程序中设置的一致（0x1234, 0x5678）
- 按键序列语法必须正确，否则无法发送
- 程序目前仅支持Windows平台的HID设备
