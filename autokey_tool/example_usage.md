# 自动按键设置工具使用示例

## 基本按键序列示例

### 1. 简单按键
```
A;
```
按下并释放A键一次

### 2. 组合键
```
Ctrl+A;
```
按下Ctrl键和A键，先释放A键再释放Ctrl键

### 3. 重复按键
```
A(5);
```
按下并释放A键5次

### 4. 延时
```
100ms;
```
等待100毫秒

### 5. 复杂序列
```
A;Ctrl+A;A(5);100ms;F1;Enter;
```
1. 按下并释放A键
2. 按下Ctrl+A组合键
3. 按下并释放A键5次
4. 等待100毫秒
5. 按下并释放F1键
6. 按下并释放Enter键

## 支持的按键列表

### 字母键
- A-Z

### 数字键
- 0-9

### 功能键
- F1, F2, F3, F4, F5, F6, F7, F8, F9, F10, F11, F12

### 特殊键
- Enter (回车)
- Esc (退出)
- Backspace (退格)
- Tab (制表符)
- Space (空格)

### 修饰键
- Ctrl
- Shift
- Alt
- Win (Windows键)

## 使用步骤

1. **连接设备**: 点击"连接设备"按钮，程序会尝试连接VID=0x1234, PID=0x5678的HID设备

2. **输入序列**: 在输入框中输入按键序列，例如：`A;Ctrl+A;A(5);100ms;`

3. **检查序列**: 点击"检查序列"按钮验证语法是否正确

4. **发送序列**: 点击"发送序列"按钮将按键序列发送到HID设备

## 错误处理

### 无效序列示例
```
InvalidKey;  # 不支持的按键
A(0);        # 重复次数必须大于0
-100ms;      # 延时必须是正数
A(;          # 语法错误
```

### 连接问题
- 确保HID设备已连接且VID/PID正确
- 检查设备驱动是否正确安装
- 确认没有其他程序占用该HID设备

## 高级用法

### 创建宏序列
```
Ctrl+C;500ms;Ctrl+V;Ctrl+V;  # 复制，等待500ms，然后粘贴两次
```

### 游戏快捷键
```
F1;100ms;F2;100ms;F3;  # 快速按F1, F2, F3
```

### 文本输入
```
H;e;l;l;o;Space;W;o;r;l;d;Enter;  # 输入"Hello World"并回车
```
