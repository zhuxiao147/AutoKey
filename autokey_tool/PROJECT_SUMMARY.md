# 自动按键设置工具 - 项目总结

## 项目概述

本项目是一个基于Qt和C++开发的自动按键设置工具，用于与HID键盘模拟设备进行交互。工具提供了直观的图形界面，支持复杂的按键序列设置和发送功能。

## 技术架构

### 核心组件

1. **主界面 (MainWindow)**
   - 基于Qt Designer设计的用户界面
   - 提供设备连接状态显示
   - 按键序列输入和验证功能
   - 状态栏消息提示

2. **HID设备管理 (HIDDevice)**
   - Windows平台HID设备枚举和连接
   - 支持指定VID和PID的设备连接
   - 实现数据发送和接收功能
   - CRC32校验和数据完整性验证

3. **按键序列解析器 (KeySequenceParser)**
   - 解析按键序列语法
   - 支持多种按键类型和操作
   - 序列验证和错误处理
   - 二进制数据转换

### 数据协议

实现了完整的数据通信协议：
```
[length:4字节][data:n字节][crc32:4字节]
```

- **长度字段**: 4字节小端整数，表示data字段长度
- **数据字段**: 按键序列的二进制表示
- **CRC32校验**: 4字节CRC32校验值，确保数据完整性

## 功能特性

### 支持的按键类型
- 字母键：A-Z
- 数字键：0-9
- 功能键：F1-F12
- 特殊键：Enter, Esc, Backspace, Tab, Space
- 修饰键：Ctrl, Shift, Alt, Win

### 按键操作语法
- **简单按键**: `"A;"` - 按下并释放A键
- **组合键**: `"Ctrl+A;"` - 同时按下Ctrl和A键
- **重复按键**: `"A(5);"` - 重复按下A键5次
- **延时操作**: `"100ms;"` - 等待100毫秒

### 用户界面
- 设备连接状态实时显示
- 按键序列输入框和语法提示
- 序列验证功能
- 一键发送按键序列
- 状态栏消息提示

## 构建和使用

### 环境要求
- Qt 5.12 或更高版本
- C++11 编译器
- Windows SDK（用于HID支持）

### 构建步骤
1. 运行 `check_env.bat` 检查环境配置
2. 运行 `build.bat` 自动构建项目
3. 生成的可执行文件位于 `build/release/AutoKeyTool.exe`

### 使用方法
1. 启动程序并连接HID设备
2. 输入按键序列（如：`A;Ctrl+A;A(5);100ms;`）
3. 点击"检查序列"验证语法
4. 点击"发送序列"发送到设备
