1. 实现自动按键设置工具，用于设置HID键盘模拟设备的自动按键序列。

2. 工具功能：
   - 可以与HID设备进行交互
   - 可以设置自动按键的按键序列

3. 界面设计
    - 使用简单直观的用户界面
    - 提供输入框用于输入按键序列
    - 提供按键用于检查按键序列是否正确

4. 技术实现
    - 使用c++编程语言实现工具的逻辑功能
    - 利用Qt库设计用户界面

5. 按键序列的语法
    - "A;"：表示按下并松开A键
    - "Ctrl+A;"：表示按下Ctrl键和A键，松开时先松开A键再松开Ctrl键
    - "A(5);"：表示按下并松开A键5次
    - "100ms;"：表示等待100毫秒

    举例：
    - "A;Ctrl+A;A(5);100ms;"：表示先按下并松开A键，然后按下Ctrl键和A键，松开时先松开A键再松开Ctrl键，接着按下并松开A键5次，最后等待100毫秒

6. HID设备交互
    - 工具可以枚举系统中连接的HID设备
    - 工具要与固定VID和PID的HID设备进行交互
    - 工具通过setreport的方式发送按键序列到固定VID和PID的HID设备
    - 工具通过getreport的方式获取固定VID和PID的HID设备的当前状态和设置是否成功
    - 固定VID和PID为0x1234和0x5678

7. 数据协议
    length: 4字节（data的长度，不包含length和crc32）
    crc32: 4字节（data的crc32校验值）
    data: 按键序列数据(每次按键占用8字节，类型为HIDKeyboardReport，每个延时占用2字节)
